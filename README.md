# আল-ইখওয়ান প্রাথমিক ও ইবতেদায়ী বৃত্তি পরীক্ষা ২০২৬ইং — সম্পূর্ণ প্রযুক্তিগত নথিপত্র

**প্রতিষ্ঠান:** আল-ইখওয়ান ইসলামী সমাজ কল্যাণ সংস্থা  
**ঠিকানা:** গল্লাসাঙ্গন, বড়লেখা, মৌলভীবাজার।  
**রেজিস্ট্রেশন নম্বর:** ২৯৯  
**প্রতিষ্ঠার তারিখ:** ০১/০১/২০০০ ইং  
**পরীক্ষার নাম:** আল-ইখওয়ান প্রাথমিক ও ইবতেদায়ী বৃত্তি পরীক্ষা ২০২৬ইং

## ১. প্রকল্প পরিচিতি
এই প্রকল্পটি মৌলভীবাজার জেলার বড়লেখা ও সংলগ্ন অঞ্চলের ৩য়, ৪র্থ ও ৫ম শ্রেণির প্রাথমিক এবং ইবতেদায়ী মাদ্রাসার শিক্ষার্থীদের মেধা অন্বেষণ ও বৃত্তি পরীক্ষা ২০২৬ পরিচালনার জন্য একটি সম্পূর্ণ বাংলা আধুনিক অনলাইন পোর্টাল। 

এর মাধ্যমে শিক্ষার্থীরা মোবাইল থেকেই বহু-ধাপের আবেদন ফর্ম পূরণ, পাসপোর্ট সাইজ ছবি ও স্বাক্ষর স্বয়ংক্রিয় কম্প্রেশনসহ আপলোড, অনন্য আবেদন নম্বর সংগ্রহ, আবেদন ট্র্যাকিং, মানি রসিদ এবং পরীক্ষার ডিজিটাল প্রবেশপত্র (QR কোড যাচাই সুবিধাসহ) প্রিন্ট করতে পারে। একইসাথে দায়িত্বপ্রাপ্ত পরীক্ষা কমিটির জন্য রয়েছে সম্পূর্ণ রিয়েল-টাইম ডেটাবেসভিত্তিক প্রশাসনিক ড্যাশবোর্ড, ফিল্টারযোগ্য অনুসন্ধান, অডিট ট্রেইল ও Excel/CSV ডেটা ডাউনলোড সুবিধা।

## ২. ব্যবহৃত প্রযুক্তি (Tech Stack)
- **ফ্রন্টএন্ড:** React 19, TypeScript, Tailwind CSS
- **আইকন ও মোশন:** Lucide React, Motion
- **কিউআর কোড জেনারেশন:** `qrcode` লাইব্রেরি
- **ক্লায়েন্ট সাইড ইমেজ রিসাইজিং:** HTML5 Canvas API (৩০০×৩০০ পিক্সেল, <১০০ KB)
- **ডেটাবেস আর্কিটেকচার:** Supabase PostgreSQL (সংস্করণ-নিয়ন্ত্রিত SQL মাইগ্রেশন ও Row Level Security সহ)
- **বিল্ড টুল:** Vite
- **ইউনিট টেস্টিং:** Node.js 22 Built-in Test Runner (`node:test`, `node:assert/strict`)

## ৩. স্থানীয় কম্পিউটারে চালানোর নিয়ম (Local Development)
১. আপনার কম্পিউটারে Node.js (সংস্করণ ২০ বা তদূর্ধ্ব) ইনস্টল করা থাকতে হবে।  
২. গিট সংগ্রহশালা ক্লোন করুন অথবা ফোল্ডারটি VS Code-এ খুলুন:
   ```bash
   git clone <আপনার-ব্যক্তিগত-GitHub-URL>
   cd al-ikhwan-exam-2026
   ```
৩. প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:
   ```bash
   npm install
   ```
৪. পরিবেশ চলক সেট করুন:
   ```bash
   cp .env.example .env
   ```
৫. ডেভেলপমেন্ট সার্ভার চালু করুন:
   ```bash
   npm run dev
   ```
৬. ব্রাউজারে `http://localhost:3000` ঠিকানায় ওয়েবসাইটটি দেখতে পাবেন।

## ৪. Supabase ডেটাবেস প্রজেক্ট তৈরির নিয়ম
১. [https://supabase.com](https://supabase.com)-এ গিয়ে একটি বিনামূল্যের অ্যাকাউন্ট তৈরি করুন।  
২. **New Project** বোতামে ক্লিক করুন।  
৩. প্রজেক্টের নাম দিন (যেমন: `alikhwan-scholarship-2026`) এবং একটি নিরাপদ ডাটাবেস পাসওয়ার্ড নির্ধারণ করুন।  
৪. অঞ্চল (Region) হিসেবে `Singapore (ap-southeast-1)` নির্বাচন করুন (বাংলাদেশের জন্য দ্রুততম পিং রেসপন্স পাওয়ার জন্য)।  
৫. প্রজেক্ট তৈরি হতে ১-২ মিনিট সময় লাগবে। তৈরি সম্পন্ন হলে **Project Settings -> API** সেকশন থেকে `Project URL` এবং `anon / public key` কপি করে আপনার `.env` ফাইলে বসান।

---

## ৫. ডেটাবেস মাইগ্রেশন চালানোর নিয়ম
১. Supabase ড্যাশবোর্ডের বাম পাশের মেনু থেকে **SQL Editor**-এ যান।  
২. **New Query** বাটনে ক্লিক করুন।  
৩. এই প্রজেক্টের `supabase/migrations/20260101000000_init_alikhwan_schema.sql` ফাইলের পুরো কোড কপি করে SQL Editor-এ পেস্ট করুন।  
৪. **Run** বাটনে চাপ দিন।  
৫. কয়েক সেকেন্ডের মধ্যে `applicants`, `exam_settings`, `notices`, `receipts`, `audit_logs` সহ সকল প্রয়োজনীয় টেবিল, ইউনিক কনস্ট্রেইন্ট, ইনডেক্স এবং Row Level Security (RLS) পলিসি সক্রিয় হয়ে যাবে।

## ৬. ফাইল স্টোরেজ ও অনুমতির নিয়ম
১. Supabase ড্যাশবোর্ডের **Storage** মেনুতে যান।  
২. **New Bucket** ক্লিক করে `applicant-documents` নামে একটি প্রাইভেট বালতি তৈরি করুন।  
৩. অ্যাপ্লিকেশনে ক্লায়েন্ট-সাইডে স্বয়ংক্রিয় ইমেজ প্রসেসিং যুক্ত করা হয়েছে যা ফাইল আপলোডের আগেই ব্রাউজারে ছবিকে পাসপোর্ট সাইজ (৩০০×৩০০ পিক্সেল) এবং ১০০ KB-র নিচে স্বয়ংক্রিয়ভাবে কম্প্রেস করে, ফলে ব্যান্ডউইথ সাশ্রয় হয় এবং ধীরগতির মোবাইলেও দ্রুত আপলোড হয়।

## ৯. Cloudflare Pages বা Vercel-এ বিনামূল্যের প্রকাশ (Free Deployment)
১. [https://dash.cloudflare.com](https://dash.cloudflare.com)-এ যান -> **Compute (Pages)** -> **Connect to Git**।  
২. আপনার GitHub সংগ্রহশালা (`al-ikhwan-exam-2026`) নির্বাচন করুন।  
৩. বিল্ড সেটিংস কনফিগার করুন:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
৪. **Environment Variables**-এ `.env.example`-এর প্রয়োজনীয় চলকগুলো যুক্ত করুন।  
৫. **Save and Deploy** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার ওয়েবসাইটটি সম্পূর্ণ বিনামূল্যে একটি দ্রুতগতির `https://<নাম>.pages.dev` সাবডোমেইনে লাইভ হয়ে যাবে।

## ১১. ব্যাকআপ ও ডেটা পুনরুদ্ধার
- **Excel/CSV ব্যাকআপ:** অ্যাডমিন ড্যাশবোর্ডের উপরে থাকা **"Excel/CSV ডেটা ডাউনলোড"** বোতামে ক্লিক করলে সরাসরি UTF-8 BOM যুক্ত CSV ফাইল নামবে যা Microsoft Excel-এ বাংলায় পরিষ্কারভাবে পড়া যায়।
- **Supabase ডাটাবেস ব্যাকআপ:** Supabase প্রজেক্টে দৈনিক স্বয়ংক্রিয় ব্যাকআপ সংরক্ষিত থাকে এবং `Database -> Backups` থেকে যেকোনো সময় ডাউনলোড করা যায়।

## ১২. জানা সীমাবদ্ধতা ও সম্ভাব্য খরচ (Cost & Limitations Reality)
১. **ওয়েব অ্যাপ্লিকেশন হোস্টিং ও ডেটাবেস:** Cloudflare Pages এবং Supabase-এর ফ্রি টায়ার ব্যবহার করে ওয়েবসাইটটি সম্পূর্ণ বিনামূল্যে চালু রাখা সম্ভব (৫০,০০০ আবেদন পর্যন্ত কোনো সার্ভার খরচ নেই)।  
২. **কাস্টম ডোমেইন:** যদি প্রতিষ্ঠান নিজস্ব ডোমেইন (যেমন: `alikhwan.org` বা `alikhwan-bd.org`) ব্যবহার করতে চায়, তবে বাৎসরিক প্রায় ১,২০০ থেকে ১,৫০০ টাকা ডোমেইন রেজিস্ট্রেশন ফি প্রয়োজন হবে।  
৩. **বাস্তব এসএমএস ওটিপি:** প্রতিটি ব্রডকাস্ট বা ওটিপি এসএমএসের জন্য টেলিকম অনুমোদিত গেটওয়েতে (যেমন: Teletalk/Grameenphone/SSL Wireless) প্রতি এসএমএসে প্রায় ০.৩০-০.৫০ পয়সা খরচ হয়। তাই পরীক্ষামূলক অবস্থায় কোনো ভুয়া ওটিপি ছাড়াই সচল নম্বর যাচাই রাখা হয়েছে।  
৪. **পেমেন্ট গেটওয়ে:** বিকাশ/নগদ-এর বাণিজ্যিক মার্চেন্ট অ্যাকাউন্ট করতে প্রতিষ্ঠানের ট্রেড লাইসেন্স/সমাজসেবা রেজিস্ট্রেশন সার্টিফিকেট প্রয়োজন হয় এবং লেনদেনে ১.২% - ১.৫% গেটওয়ে চার্জ প্রযোজ্য হতে পারে। এই সিস্টেমে একটি নিরাপদ স্যান্ডবক্স সিমুলেটর দেওয়া হয়েছে যা প্রতিষ্ঠানের অনুমোদন পেলে সাথে সাথে রিয়েল গেটওয়েতে রূপান্তর করা যাবে।
